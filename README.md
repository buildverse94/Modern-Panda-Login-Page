# 🐼 Panda Login Page

A modern and responsive Panda-themed Login Page built using HTML, CSS, and JavaScript. This project features a stylish dark UI, custom form design, social media icons, glowing effects, and a unique panda illustration.

## 🚀 Features

- Modern Dark UI Design
- Panda-Themed Layout
- Responsive Design
- Custom Styled Form Fields
- Password Visibility Toggle
- Social Media Icons
- Smooth Hover Effects
- Clean and Organized Code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚡ Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/LoginPage6.git
```

2. Open the project folder

```bash
cd LoginPage6
```

3. Run the project

Simply open `index.html` in your browser.
